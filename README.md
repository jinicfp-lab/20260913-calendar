# 2027 To Do Calendar

2027년 한국 달력 기준으로 날짜별 할 일을 관리할 수 있는 웹 캘린더 앱입니다. HTML, CSS, JavaScript만으로 구성되어 별도의 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.

## 주요 기능

- 2027년 1월부터 12월까지 월별 달력 보기
- 날짜를 선택해 일자별 할 일 입력
- 체크박스로 할 일 완료 여부 표시
- 완료된 할 일 취소선 표시
- 할 일 삭제
- 브라우저 `localStorage`를 이용한 할 일 저장
- 한국 달력 기준 색상 적용
  - 토요일: 파란색
  - 일요일 및 공휴일: 붉은색
- 2027년 한국 공휴일 및 대체공휴일 표시
- Pretendard 폰트 적용
- 이모지와 그라디언트 없이 보라색 중심의 차분한 UI 구성

## 실행 방법

가장 간단한 방법은 `index.html` 파일을 브라우저에서 여는 것입니다.

로컬 서버로 실행하려면 `outputs` 폴더에서 아래 명령어를 실행합니다.

```bash
python -m http.server 5173 --bind 127.0.0.1
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:5173/index.html
```

## GitHub에 올리는 방법

이 프로젝트는 정적 웹앱이므로 아래 파일들을 GitHub 저장소의 루트에 올리면 됩니다.

```text
index.html
styles.css
script.js
README.md
.gitignore
```

GitHub Pages로 배포하려면 저장소에서 `Settings` → `Pages`로 이동한 뒤, 배포 브랜치를 선택하고 루트 폴더를 공개하면 됩니다.

## 파일 구조

```text
outputs/
  index.html    앱의 기본 HTML 구조
  styles.css    화면 디자인과 반응형 스타일
  script.js     달력 렌더링, 할 일 추가, 완료, 삭제, 저장 로직
  README.md     서비스 설명 문서
```

## 사용 방법

1. 상단의 `이전`, `다음` 버튼으로 원하는 달로 이동합니다.
2. 달력에서 할 일을 등록할 날짜를 선택합니다.
3. 오른쪽 입력창에 할 일을 작성하고 `추가` 버튼을 누릅니다.
4. 완료한 할 일은 체크박스를 선택해 표시합니다.
5. 필요 없는 할 일은 `삭제` 버튼으로 제거합니다.

## 저장 방식

할 일 데이터는 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저에서 다시 열면 이전에 입력한 할 일을 계속 확인할 수 있습니다.

저장 키는 아래 값을 사용합니다.

```text
todo-calendar-2027
```
